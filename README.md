# Sports Ticket Reservation DB Project

Database Design final project: a sports ticket reservation and purchase platform.

## Team Members

- Saghar Ramezani
- Shamim Sedaghat Teymuri
- Sarina Asadi

## Tech Stack

- Backend: Java
- Database: PostgreSQL
- Database Access: JDBC, raw SQL, no ORM
- Frontend: HTML, CSS, Vanilla JavaScript
- Cache / OTP: Redis
- Search: ElasticSearch
- IDE: IntelliJ IDEA / PyCharm

## Project Phases

1. ER Diagram and database design
2. Tables, seed data, SQL queries, stored procedures
3. Backend API implementation
4. UI and ElasticSearch integration
